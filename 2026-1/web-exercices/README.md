# Exercícios Web (2026.1)

Pasta destinada ao armazenamento dos exercícios e práticas desenvolvidas em Desenvolvimento Web (HTML5, CSS3 e JavaScript) durante a graduação em Engenharia de Software.

## Arquivos Contidos

* Estruturação de páginas com HTML5.
* Estilização, layout e responsividade com CSS3.
* Lógica de programação e manipulação do DOM com JavaScript.
* Projetos e práticas de fixação web.
